# 株価分析ツール（Moving Average Crossover Tool）

## ■ 概要

本ツールは株価データを取得し、移動平均線（MA5・MA25）を用いたトレンド分析およびクロスシグナル（ゴールデンクロス / デッドクロス）の可視化を行うPythonアプリケーションです。

ラインチャートとローソク足チャートの両方に対応し、売買判断の補助を目的としています。

---

## ■ 機能

* 株価データ取得（Yahoo Finance）
* 移動平均線の計算（MA5 / MA25）
* トレンド判定

  * 上昇トレンド
  * 下降トレンド
* クロスシグナル検出

  * ゴールデンクロス（短期線が長期線を上抜け）
  * デッドクロス（短期線が長期線を下抜け）
* チャート表示

  * ラインチャート（matplotlib）
  * ローソク足チャート（mplfinance）
* クロス発生位置の可視化（▲▼マーカー）

---

## ■ 工夫した点

* 分析処理（analysis）と描画処理（plot）を分離し、保守性を向上
* クロス検出ロジックを関数化し再利用可能に設計
* 欠損値（NaN）や空データに対する例外処理を実装し、安定動作を実現
* ラインチャートとローソク足チャートの両対応
* クロスシグナルを視覚的に分かりやすく表示
